## Назначение

Этот skill нужен для регулярной ревизии финансовых целей: он помогает понять, идет ли пользователь по выбранной траектории или уже начал отставать.

## Когда применять

Применяй skill, если пользователь:
- спрашивает, как продвигается цель;
- хочет проверить, укладывается ли он в план;
- просит оценить текущий темп накопления;
- хочет понять, почему цель начала отставать.

## Инструменты

- `get_goals`: получить полный список целей пользователя;
- `income_consult_tool`: проверить факты по доходам;
- `outcome_consult_tool`: проверить факты по расходам;
- `search_operations_tool`: найти причины отклонений в операциях;
- `calculate_expression`: посчитать разницу между планом и фактом;
- `execute_python_code`: сделать более детальную проверку по месяцам;
- `calculate_trajectories`: перепроверить реалистичность текущего сценария.

## Основной workflow

1. Выбери цель, которую нужно проверить.
2. Вызови `get_goals`, получи полный список целей и выбери цель, которую нужно проверить.
3. Собери актуальные факты по доходам и расходам.
4. Сравни ожидаемый темп с фактической возможностью откладывать деньги.
5. Если видно отклонение, найди его причину:
   - снижение дохода;
   - рост обязательных расходов;
   - всплеск нерегулярных трат;
   - слишком оптимистичная исходная траектория.
6. При необходимости пересчитай траекторию через `calculate_trajectories`.
7. Сформулируй статус цели и предложи корректирующее действие.

## Статусы, которые можно использовать

- цель идет по плану;
- есть умеренное отклонение, но цель еще можно удержать;
- цель заметно отстает и требует пересмотра сценария;
- цель в текущем виде нереалистична.

## Правила и ограничения

- Не называй цель "сорванной" без проверки фактов.
- Если отклонение основано на одной аномальной операции, скажи это отдельно.
- Если нужна глубокая сверка по периодам, используй `execute_python_code`.
- Если нужен пересмотр плана, явно отправляй пользователя в skill построения траекторий.
- Если `get_goals` вернул несколько похожих целей, сначала уточни, какую из них нужно аудировать.

