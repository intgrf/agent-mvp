## Назначение

Этот skill отвечает за фактический разбор расходов без догадок: сколько, на что, когда и за счет каких операций пользователь тратил деньги.

## Когда применять

Применяй skill, если пользователь:
- спрашивает о сумме трат за период;
- просит анализ категории расходов;
- хочет сравнить траты между месяцами;
- просит показать конкретные операции;
- хочет понять, где произошел рост расходов.

## Базовый подход

Сначала отвечай фактами, потом интерпретируй. Не начинай с советов по экономии, пока не показал структуру расходов и не подтвердил цифры инструментами.

## Инструменты и их роли

- `outcome_consult_tool`: быстрый ответ на фактологический вопрос о расходах;
- `search_operations_tool`: список операций для подтверждения, детализации и поиска аномалий;
- `income_consult_tool`: подключай, если нужно сравнить траты с доходом или оценить нагрузку на бюджет;
- `calculate_expression`: используй для долей, темпов роста, средних значений и сравнений.

## Workflow

1. Уточни запрос:
   - период;
   - категория;
   - нужна ли детализация по операциям;
   - нужно ли сравнение с другим периодом.
2. Получи факт через `outcome_consult_tool`.
3. Если пользователь просит доказательность или детали, вызови `search_operations_tool`.
4. Если нужен сравнительный анализ:
   - собери данные по каждому периоду;
   - рассчитай разницу и процент изменения через `calculate_expression`.
5. Если нужен контекст устойчивости бюджета, сравни расходы с доходом через `income_consult_tool`.
6. Сформулируй вывод в двух слоях:
   - факты;
   - краткая интерпретация.

## Вопросы, которые нужно уточнять

Уточняй запрос, если пользователь не указал:
- период: "за месяц", "в марте", "за последние 3 месяца";
- категорию: "еда", "транспорт", "развлечения";
- тип ответа: только сумма или еще операции;
- цель анализа: просто посмотреть, найти перерасход или подготовить рекомендации.

## Как делать хороший разбор

### Для простого вопроса

Если пользователь спрашивает только "сколько я потратил на еду", достаточно:
- назвать сумму;
- указать период, если он известен;
- предложить показать операции при необходимости.

### Для расширенного анализа

Если нужен содержательный разбор, покажи:
- итоговую сумму;
- крупнейшие составляющие;
- повторяющиеся траты;
- необычные или разовые списания;
- изменение к прошлому периоду.

### Для сравнения периодов

Всегда отвечай на три вопроса:
- сколько было в каждом периоде;
- на сколько изменилась сумма;
- чем это изменение могло быть вызвано по операциям.

## Что считать аномалией

Помечай как потенциальную аномалию:
- редкую крупную операцию;
- скачок в категории без очевидной сезонной причины;
- серию однотипных списаний за короткий срок;
- рост категории, который заметно опережает рост дохода.

Подтверждай аномалии через `search_operations_tool`, а не через догадку.

## Формат ответа

Используй компактную структуру:

```markdown
За [период] расходы на [категория] составили [сумма].

Что видно:
- ...
- ...
- ...

Если нужно, могу показать операции или сравнить с другим периодом.
```

## Если пользователь просит "почему так много"

Не отвечай общими словами. Сначала:
1. подними операции;
2. выдели крупные и повторяющиеся списания;
3. посчитай их вклад;
4. только потом дай объяснение.

## Ограничения

- Не называй причины, если они не следуют из данных.
- Не смешивай расходы и переводы без подтверждения.
- Не округляй значимые суммы грубо, если точность важна для вывода.
- Не подменяй фактологический ответ финансовой консультацией.
