## Назначение

Этот skill помогает превращать финансовый анализ в артефакт, с которым можно работать дальше: отчет, заметку, черновик рекомендаций или файл с промежуточными расчетами.

## Когда применять

Применяй skill, если пользователь:
- просит сохранить отчет;
- хочет получить структурированный файл по итогам анализа;
- хочет вести рабочие заметки по целям, расходам или продуктам;
- просит экспортировать расчеты или промежуточные выводы.

## Инструменты

- `read_file_tool`, `write_file_tool`, `edit_file_tool`, `list_dir_tool`: работа с файловой системой;
- `get_goals`, `income_consult_tool`, `outcome_consult_tool`, `search_operations_tool`: собрать данные; помни, что `get_goals` возвращает полный список целей, а нужную цель нужно выбрать отдельно;
- `execute_python_code`: при необходимости подготовить таблицы, агрегаты или форматированные блоки;
- `calculate_expression`: посчитать ключевые показатели.

## Основной workflow

1. Определи, какой артефакт нужен пользователю:
   - краткая заметка;
   - полный Markdown-отчет;
   - файл с расчетами;
   - обновление существующего документа.
2. Если работа идет с уже существующим файлом, сначала прочитай его через `read_file_tool`.
3. Собери фактические данные и выводы.
4. Сформируй структуру документа:
   - контекст;
   - данные;
   - выводы;
   - рекомендации или следующие шаги.
5. Если нужно, подготовь вычисленные таблицы или агрегаты через `execute_python_code`.
6. Сохрани результат через `write_file_tool` или обнови через `edit_file_tool`.

## Хорошие форматы артефактов

Подходящие варианты:
- `report.md` для читаемого анализа;
- `notes.md` для рабочей заметки;
- `calculations.txt` или аналогичный файл для промежуточных вычислений;
- отдельные файлы по целям или периодам, если анализ крупный.

## Правила и ограничения

- Не записывай в файл неподтвержденные выводы как факты.
- Если обновляешь существующий файл, сначала прочитай его и сохрани стиль структуры.
- Не создавай лишние файлы без причины.
- Внутри отчета отделяй данные от интерпретации.

## Формат типового отчета

```markdown
# Финансовый отчет

## Контекст
...

## Ключевые данные
...

## Выводы
...

## Следующие шаги
...
```

## Когда особенно полезен этот skill

Используй его после:
- анализа расходов;
- ревизии прогресса по целям;
- сравнения банковских продуктов;
- сложного сценарного моделирования, которое нужно сохранить.
